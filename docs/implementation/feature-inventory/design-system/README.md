# UI Design System

## Feature

- UI Design System (`docs/design/ui/design-system.md`)

## Description

- One design language for every app: purple and white, bento grid, Playfair Display, Hugeicons, light and dark themes.

## Capability Leverage

- A consistent, human-made interface is the product's main marketing.
